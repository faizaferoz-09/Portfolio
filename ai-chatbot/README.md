# AI Assistant Chatbot

A real Gemini-powered chatbot. Answers are generated by the Google Gemini API. They are not hardcoded or picked from a list.

The browser never talks to Gemini. It only calls this project's Express server. The server holds the API key and asks Gemini for each user question.

## Features

- Live Gemini answers for every question
- User and AI message bubbles with avatars
- Send button, Enter to send, Shift + Enter for a new line
- "AI is thinking..." typing indicator
- Auto-scroll, Clear Chat, session history, New Chat
- Welcome message and suggested questions
- Responsive desktop and mobile layout
- Friendly error messages

## Technologies

- HTML5, CSS3, JavaScript (ES6+)
- Node.js and Express.js
- Google Gemini API with the official `@google/genai` SDK
- dotenv
- Fetch API

## Install Node.js

1. Download Node.js LTS from [https://nodejs.org/](https://nodejs.org/).
2. Run the installer.
3. Close and reopen the terminal.
4. Check:

```bash
node -v
npm -v
```

## Install npm packages

Open a terminal in this project folder and run:

```bash
npm install
```

This installs Express, dotenv, and `@google/genai`.

## Get a Gemini API key

1. Open [Google AI Studio](https://aistudio.google.com/apikey).
2. Sign in with a Google account.
3. Create an API key.
4. Copy the key.

## Set up `.env`

Create `.env` in the project root (or copy `.env.example`):

```
GEMINI_API_KEY=YOUR_API_KEY_HERE
```

Replace `YOUR_API_KEY_HERE` with the real key. No quotes. No spaces.

Do not put the key in `index.html`, `style.css`, or `script.js`. `.env` is listed in `.gitignore`.

## How to run the project

```bash
npm start
```

## Browser URL

Open [http://localhost:3000](http://localhost:3000)

Do not open `public/index.html` as a file. The `/chat` route only works through the server.

## How to test that Gemini is working

1. Type: `Explain JavaScript in simple words.`
2. Click Send (or press Enter).
3. You should see your question, then "AI is thinking...", then a unique Gemini-generated explanation.
4. Ask a second question such as `What is an API?` — the answer should be different and relevant.

If you still see a configuration error, the `.env` key is missing or still a placeholder. Restart the server after changing `.env`.

## Gemini model and SDK

Default model: **gemini-2.5-flash** (fast, good for chat). Official method:

```js
import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });
const response = await ai.models.generateContent({
  model: "gemini-2.5-flash",
  contents
});
```

This is not the deprecated `@google/generative-ai` / `getGenerativeModel` API.

## Common errors and solutions

| Problem | Solution |
| --- | --- |
| `npm` is not recognized | Install Node.js, then open a new terminal. |
| Chatbot is not configured | Put a real key in `.env` and restart `npm start`. |
| Invalid API key | Create a new key in AI Studio and paste it again. |
| Rate limit / too many requests | Wait and try again. |
| Network / could not process | Keep the server running and use http://localhost:3000. |
| Cannot find module | Run `npm install`. |
| Port in use | Set `PORT=3001` in `.env`. |
| Empty send does nothing | Expected. Blank messages are blocked. |
